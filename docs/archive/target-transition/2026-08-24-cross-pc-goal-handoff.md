## Frozen architecture and non-negotiable decisions

- Project is the top-level authority. Overview, Canvas, Media, Production, Delivery, Chat, Results,
  History, and Commander all project the same domain objects.
- Target modules must not import the Legacy Canvas-as-Project, Resource, Prompt, Preset, Template,
  Guide Injection, Commander runtime, or host-authored workflow paths.
- There is one typed 40-tool model catalog, one Dispatcher/guard pipeline, one Run event history, and
  one target IPC router. No compatibility aliases, dual writes, hidden fallback, or second Commander.
- Model-visible history is derived from immutable events. Private reasoning, credentials, local paths,
  raw provider payloads, and secret sentinels never enter public history, UI, search, logs, or export.
- Every side effect uses its owning authority and typed CAS/revision rules. Protected mutations require
  exact confirmation. Unknown provider submission state never causes automatic duplicate submission.
- Media identity is an immutable verified hash, not a path. Project use is a separate
  `ProjectMediaRef` relationship.
- TaskList is optional Commander progress, not a product lifecycle or fixed film phase machine.
- All valid generated results are retained and shown. Evaluation never silently chooses the creative
  winner; the user selects, rejects, refines, or uses a result as a reference.
- Real user data stays untouched until the separately approved I8 cutover sequence. Migration rehearsal
  uses copied, disposable inputs only.
