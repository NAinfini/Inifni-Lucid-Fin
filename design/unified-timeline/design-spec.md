# 统一时间线编辑器设计规范

## 目标与边界

将现有占位的 `EditView` 与 `AudioView` 收敛为一个 `Timeline` 工作区，让用户在同一条时间轴上编排当前 Canvas 的视频、独立音频与字幕，并为 Final Export 生成可审阅的时间线事实来源。

本设计只覆盖：单一顺序视频轨、多条独立音频轨、字幕轨、预览播放、拖动/裁切/删除、音量与静音、字幕 cue 编辑和持久化状态。明确不包含叠加视频、画中画、转场、变速、关键帧、自动 ducking、自动转写或特效工作流。

## 设计原则

- 延续现有冷中性深色编辑器：`background` / `card` / `surface` 层级、蓝色主焦点、紫色视频、绿色音频；不创建新的视觉语言。
- 低噪音优先：时间线内容是主角，常驻控件只保留播放、添加媒体、缩放和轨道级控制。
- 媒体引用是非破坏性的：删除时间线片段不删除 Canvas 节点或 Asset 源文件。
- 视频内嵌音频始终属于视频片段。它不生成第二个音频资产或伪装成独立音轨。
- 所有时间计算和持久化均使用整数毫秒；界面时间码统一显示为 `HH:MM:SS.mmm`。

## 信息架构

### 视图入口

- 将视图切换器中的 `Edit` 与 `Audio` 合并为单个 `Timeline` 入口。
- 视图切换器最终保留 `Canvas`、`Timeline`、`Materials`。
- 左侧聊天/Canvas 分组栏、左右工具栏及现有可调整侧栏继续存在；Timeline 只替换中央工作区内容。

### 中央工作区

从上到下分为四层：

1. **标题工具行（40px）**
   - 左侧：`Canvas 名称 / Timeline`。
   - 右侧或标题旁：安静的次级按钮 `Add media`。
   - 不新增重复的音频/字幕模式切换。
2. **播放器（约可用高度的 38%）**
   - 黑色 16:9 预览区域居中，保持画面完整显示。
   - 下方仅保留上一片段、播放/暂停、下一片段和精确时间码。
   - 点击预览区不改变时间线选择；空格在非文本输入焦点时播放/暂停。
3. **时间标尺与轨道区（约可用高度的 62%）**
   - 左侧 148–160px 固定轨道头；右侧为同步横向滚动的标尺与片段区。
   - 标尺置顶，蓝色播放头跨越所有轨道。
   - 轨道垂直滚动，标尺、轨道头和片段区保持对齐。
4. **底部导航行（32px）**
   - 横向滚动条位于片段区下方。
   - 缩放减号、滑杆、加号固定在右端；缩放以指针位置为锚，指针不在时间线时以播放头为锚。

### 属性检查器

复用应用现有右侧 Inspector 通道，不创建浮动卡片或永久叠层。

- 视频片段：源、源入点、源出点、时长、`Embedded audio` 开关及片段音频增益。
- 独立音频片段：源、时间线开始、源入点、源出点、时长及片段增益。
- 字幕 cue：正文、开始、结束、时长、保存状态和当前 CAS hash。
- 属性输入的标签明确写成 `Start (ms)` / `End (ms)`，值为整数；标尺和播放器使用格式化时间码，禁止把时间码与 `ms` 后缀混写。

## 轨道与片段

### 主视频轨

- 只能存在一条 `Video` 轨；视频片段不重叠，按播放顺序相邻排列。
- 从 Canvas 或 Assets 添加视频时，默认追加到末尾；拖放到片段之间显示清晰的插入线。
- 横向拖动视频片段用于重排。调整入/出点后，后续视频片段自动 ripple，保持单一连续顺序。
- 视频有音频流时，默认启用：片段底部显示一条依附于该片段的细波形带和扬声器图标。选中后可在 Inspector 调整增益或静音。
- 视频没有音频流时，不绘制波形，扬声器位置显示不可用状态与 `No embedded audio` 提示。
- 不提供将内嵌音频“拆出”为独立音轨的入口。

### 独立音频轨

- 用户可以创建多条音频轨；每条轨道头包含名称、静音按钮和 `dB` 增益值。
- 音频片段可在时间轴上自由移动、跨音频轨移动并从两端裁切。
- 同一音频轨内片段不可重叠；需要同时播放时放入另一条音频轨。
- 轨道增益与片段增益均可用：轨道头负责整轨，Inspector 负责选中片段。
- 不提供 Solo、ducking、关键帧或自动混音。

### 字幕轨与 CAS cue

- 可创建多条字幕轨，例如不同语言；轨道头提供可见性开关，不使用音频的“静音”措辞。
- cue 块显示最多两行正文摘要；拖动改变时间位置，两侧把手调整开始/结束。
- 正文在 Inspector 编辑。保存中显示 `Saving…`，成功显示 `Saved` 与短 hash；状态使用文字和图标，不能只依赖颜色。
- 每次成功写入都产生新的 CAS 内容并原子替换 cue 引用。冲突时保留本地文本并显示 `Cue changed elsewhere`，只提供 `Reload latest` 与 `Keep mine as new revision`，不得静默覆盖或自动合并。

## 添加媒体

- `Add media` 打开紧凑的源选择器，只有 `Canvas` 与 `Assets` 两个来源标签，并只列出视频、音频。
- 支持从选择器拖入目标轨，也支持明确的 `Add`：视频追加到主视频轨；音频添加到选中音频轨的播放头位置，没有选中轨时创建一条新轨。
- 字幕通过轨道头的 `Add subtitle track` 与轨道内 `Add cue at playhead` 创建，不暗示自动转写。
- 每次添加都是显式用户动作；切换到 Timeline 不会自动把 Canvas 上所有媒体加入时间线。

## 交互规则

- 单击选择；`Shift` 单击允许同类多选，仅用于批量移动或删除，不提供组合效果。
- 拖动片段主体移动，拖动两端裁切；裁切把手至少有 12px 可命中区，视觉宽度可以更窄。
- `Delete` / `Backspace` 删除时间线引用，沿用应用现有 Undo/Redo；不弹删除源文件确认框。
- 单击标尺或拖动播放头 scrub；播放时只更新播放头和必要的时间码，不触发整棵轨道重绘。
- 鼠标滚轮垂直滚动轨道；`Shift + wheel` 横向滚动；`Ctrl/Cmd + wheel` 缩放。
- 键盘焦点在时间线时：`Space` 播放/暂停，左右方向键移动 100ms，`Shift + 左右` 移动 1000ms，`Alt + 左右` 移动 1ms。文本编辑时这些快捷键不生效。
- 所有拖动结果在释放时取整到整数毫秒；输入非法值时就地报错，不静默夹取或保存。

## 状态与反馈

- **空时间线：** 在 Video 轨显示 `Drag a video from Canvas or Assets` 和 `Add media`；音频、字幕可以预先编排，但 Final Export 在没有主视频时不可批准。
- **正在读取元数据：** 片段保留稳定尺寸，内部显示短骨架和 `Reading media…`，避免轨道跳动。
- **源不可用：** 片段使用斜纹与错误图标，保留时序位置并显示 `Source unavailable`；该状态阻止 v2 manifest 审批。
- **超出主视频时长：** 音频或 cue 的越界部分使用红色尾缘标记并列入校验问题，不自动裁切。
- **保存失败：** 字幕 Inspector 保留未保存文本和重试动作；离开前明确提示未保存状态。
- **播放错误：** 预览区内显示可操作错误，时间线结构仍可编辑。

## 视觉规范

- 基础色完全取自当前主题变量：`background`、`card`、`surface`、`border`、`foreground`、`muted-foreground`、`primary`。
- 类型色沿用现有节点语义：视频紫 `#a855f7`，音频绿 `#22c55e`；字幕使用克制的琥珀色，并同时使用字幕图标/标签。
- 非选中片段使用低饱和半透明填充；选中态统一使用蓝色 2px 焦点环，避免把类型色误读成焦点。
- 边框 1px、圆角约 6px；不使用玻璃拟态、渐变、大面积高饱和填充或卡片嵌套。
- 字体延续 Inter/system，正文 12–13px，轨道元数据 10–11px；时间码使用等宽数字。
- 常规按钮命中区不低于 28px，关键播放按钮为 32px。

## 自适应

- 中央编辑区宽度充足时：播放器、时间线和右侧 Inspector 同时显示。
- 中央编辑区低于约 900px 时：Inspector 作为现有右侧可开关面板；轨道头缩到 132px，隐藏非必要片段文字但保留图标与 tooltip。
- 可用高度低于约 640px 时：播放器缩到最小 180px，高度继续不足时允许用户折叠播放器；时间线不得被压到少于三条可见轨道。
- 不提供移动端重新排版；这是桌面精密编辑器。

## 可访问性

- Timeline 是有名称的区域；轨道以列表呈现，片段使用 roving tabindex，Tab 不遍历数百个不可见片段。
- 每个片段的可访问名称包含类型、名称、开始、结束和静音状态。
- 拖动、裁切、静音和保存结果通过节流的 `aria-live` 文本报告，例如 `Music moved to 12,480 milliseconds`。
- 所有鼠标操作在 Inspector 中都有等价的数字输入；轨道静音使用 `aria-pressed`。
- 颜色不是唯一状态信号；错误、保存、内嵌音频、字幕均配有文字或图标。
- 高对比主题继续使用主题 token；遵守 `prefers-reduced-motion`，播放头以外不做持续动画。

## 性能约束

- 轨道和片段按可视时间范围虚拟化，只渲染 viewport 加少量 overscan；水平滚动与缩放不能遍历全部片段做 DOM 更新。
- 各轨片段按 `startMs` 排序，范围查询和命中测试使用二分定位，目标复杂度为 `O(log N + visible)`，禁止在每次 pointermove 中全量扫描。
- 波形包络按资产和缩放层级缓存；缩放/滚动复用采样结果，不在 React render 或播放帧内解码音频。
- 拖动期间仅使用局部状态和 transform，并以 `requestAnimationFrame` 更新；释放后一次提交持久化状态。
- 播放头使用独立 compositor layer；播放时不要更新整个 Redux 时间线对象。
- 只解码预览窗口附近需要播放的媒体；离屏缩略图与波形惰性加载。
- 虚拟化不能破坏键盘定位：焦点移动到离屏片段时先滚动，再挂载并聚焦目标。

## Final Export 约束

- 审批对象是不可变的 v2 manifest，引用当前 Timeline、所有媒体 CAS、字幕 cue CAS 与精确整数毫秒参数。
- 审批前校验：主视频存在且顺序有效、所有源可解析、音频与字幕不越界、没有未保存或冲突 cue。
- 审批后的任何时间线编辑都会使 manifest 失效并回到待审阅状态；不得继续使用旧批准结果。
